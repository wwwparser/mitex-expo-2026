Это статический снимок: регулярное автоматическое обновление не включалось. Ключи XMLRiver находятся только в игнорируемом `.env`. Досье поиска и полные сырые посты исключены из Git; публичная витрина содержит выдержки и ссылки на оригиналы.

Сборщики разделов: `research_search.py`, `research_additional.py`, `collect_program.py`, `collect_speakers.py`, `search_speakers.py`, `merge_discoveries.py`, `classify_speaker_telegram.py`, `collect_feed.py`, `collect_youtube.py`, `inspect_video_meta.py`, `prepare_videos.py`, `prepare_program_texts.py`, `prepare_novelties.py`. Сначала собирается программа и спикеры, затем применяются проверенные поисковые находки, затем классифицируются Telegram-ссылки и собирается лента. `prepare_program_texts.py` заменяет исходные описания редакторскими текстами и добавляет отдельный анонс конференции. Поиск YouTube в этом окружении запускался с `--proxy`, поскольку прямой DNS не разрешал youtube.com.
Открыть **site/index.html** в браузере: сервер и ключи не нужны.

## Полный сбор контактов

Итог первого обхода сайтов, до XMLRiver: проверены все 704 карточки; у 567 участников указан сайт, у 137 — нет. Проверены 572 уникальных домена, 402 доступны, 170 остались недоступны. Повтор без прокси восстановил доступ к 50 сайтам. Найдено 78 уникальных Telegram-ссылок у 68 участников: 54 публичных канала, 4 бота, 13 профилей и 7 неподтверждённых адресов. После XMLRiver показатели увеличились, как указано выше. Список недоступных страниц — в `data/site/contact_report.json`.

После первоначального MVP запущен полный обход 704 карточек и всех указанных сайтов навыком `contact-scraper`. Для каждого уникального домена проверяется главная и до шести контактных страниц. Общие сайты нескольких участников обходятся один раз, а результаты связываются с каждой соответствующей компанией.

```powershell
python -X utf8 scripts/full_contacts.py --workers 6
python -X utf8 scripts/classify_telegram.py
python -X utf8 scripts/build.py
python -X utf8 scripts/check.py
```

`full_contacts.py` сохраняет результат после каждой карточки и каждого сайта. Повторный запуск продолжает недостающие записи. Недоступные сайты сохраняются как `unreachable`, а не как «контактов нет». Этапы можно запускать отдельно через `--stage details`, `--stage sites`, `--stage finalize`. Ошибки формата адресов исправляются с сохранением исходных значений; несколько склеенных сайтов разделяются.

Для повторной попытки без системного прокси:

```powershell
python -X utf8 scripts/full_contacts.py --stage sites --direct --retry-unreachable --retry-failed-pages --workers 8
```

`--direct` задаёт `trust_env=False` только HTTP-клиенту сайтов: не использует системные/переменные окружения прокси и не меняет настройки Windows. Успешные контакты предыдущего прохода сохраняются, результаты повторных попыток объединяются. Карточки каталога и проверка Telegram используют отдельный клиент.

Результаты: `data/site/exhibitors.json`, `exhibitors.csv`, `exhibitors.xlsx`, `contact_report.json` и `channels.json`. Подробный журнал сайтов — `data/contacts/contacts.jsonl` (не публикуется). Telegram проверяется по публичному превью без авторизации: канал, группа, бот, профиль или неподтверждённая ссылка. Контакты включают URL страниц, на которых они найдены.

Исходник Вашего навыка сохранён в `src/vendor/contact_scraper.py`; используется его реальный обход `crawl_site`, а не сокращённая замена. В адаптере добавлены источники контактов, строгая проверка доменов Telegram и связь с карточками MITEX. Платные LLM не вызываются; браузерный fallback в этом прогоне не включён.

## Что реализовано в первоначальном MVP

- Снимок всех 704 уникальных карточек, которые официальный каталог вернул через `limit=1000`; отсутствие оставшейся пагинации проверяется кодом.
- Поиск по компании, описанию и стенду, фильтры по стране и наличию контактов, пагинация по 24 карточки, сброс фильтров.
- Сбор подробных контактов первых 12 карточек и попытка обогащения первых 6 сайтов. Фактические результаты и ошибки — в `data/site/meta.json`. Это ограничение MVP, а не полный обход компаний.
- Открытые ссылки на сайты, email, телефоны и соцсети; CSV для скачивания и JSON для дальнейшей обработки.
- Разделы программы, Telegram, видео и новинок с честными статусами. Анонс FELISATTI взят из описания участника и отделён от подтверждённых новинок.
- Кэш HTTP, таймауты, три попытки, сохранение после каждой карточки и продолжение сбора.

## Первоначальный ограниченный сбор

Проверенные зависимости уже доступны в текущем Python-окружении. Для нового окружения:

```powershell
python -m pip install -r requirements.txt
python -X utf8 scripts/collect.py
python -X utf8 scripts/build.py
python -X utf8 scripts/check.py
```

Для полного обхода карточек и сайтов:

```powershell
python -X utf8 scripts/collect.py --details 704 --enrich 704
python -X utf8 scripts/build.py
```

Без `--refresh` используются кэш и успешные предыдущие результаты. При изменении каталога сверить количество и передать актуальный лимит карточек. `--refresh` обновляет каталог, карточки, сайты и программу в пределах указанных лимитов.

Обычный сбор не вызывает платные API, не входит в Telegram и не отправляет сообщения. Посты Telegram не собраны. Поиск YouTube и соцсетей спикеров не выполнялся. После полного сбора повторять ограниченный `collect.py` не нужно: основной путь обновления — `full_contacts.py` выше.
