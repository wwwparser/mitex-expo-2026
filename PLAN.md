# Оценка идеи и план реализации

Обновление 14 октября 2026: этап полного каталога и обхода всех указанных сайтов выполнен после MVP. Все 704 карточки проверены; контакты сайтов собраны навыком contact-scraper с повтором неудачных запросов без системного прокси. Telegram-адреса классифицированы по публичным превью. Точные показатели — в README.md и data/site/meta.json. Приведённые ниже формулировки «только выборка» описывают первоначальный прототип; посты, YouTube и программа остаются отдельными этапами.

## Вывод

Идея жизнеспособна как независимый справочник инструментального рынка: единый поиск компаний, стендов, контактов, публикаций и продукции. Главная ценность — связать материалы с конкретным участником и сохранять источник каждого факта. Полный каталог и полный набор доступных контактов — разные показатели, их нельзя объединять в один процент готовности.

На 14 октября 2026 выставка ещё не состоялась. Организатор указывает 10–13 ноября 2026 года. Сейчас можно подготовить каталог и ленты анонсов; итоговый обзор показанных новинок следует составить после выставки, по подтверждающим материалам.

## Три варианта

Оценки ниже — инженерный диапазон для одного исполнителя, а не обещание календарного срока. Ручная проверка иностранных компаний и полнота источников могут увеличить работу.

| Вариант | Стек | Первый MVP | Полная версия идеи | Применение |
|---|---|---|---|---|
| **1. Статический навигатор — выбран** | Python, requests, BeautifulSoup, JSON/CSV, HTML/CSS/JS; позже GitHub Pages или обычный хостинг | 6–12 часов | 40–70 часов, 5–9 рабочих дней | Быстро собрать и проверить данные, разовые снимки |
| 2. Сервис с регулярным обновлением | Python/FastAPI, SQLite, фоновые задания, HTML/JS или React, VPS | 16–28 часов | 60–100 часов, 8–13 дней | Ежедневные обновления, история постов, ручное подтверждение |
| 3. Редактируемый портал | WordPress, собственный импорт JSON, типы записей компаний/событий/продуктов, Python-сборщики | 20–36 часов | 70–110 часов, 9–14 дней | Редактор регулярно публикует обзоры и правит карточки |

Текущий прототип реализует ядро варианта 1 и ограниченный обход контактов. Сложный сервер пока не нужен: фильтрация нескольких сотен карточек работает в браузере. Вариант 2 имеет смысл после проверки полезности навигатора и требований к обновлению.

## MVP и следующие этапы

1. **Каталог и источники, 6–12 часов.** Снимок всех участников, идентификаторы, страны, стенды, поиск, выгрузка, статусы покрытия, локальная сборка. Ядро уже реализовано.
2. **Контакты всех компаний, ещё 8–16 часов.** Обход всех карточек, главных и контактных страниц, сопоставление доменов, обработка недоступных сайтов; сохранение provenance для каждого контакта, единая нормализация телефонов и отчёт по ошибкам. Сейчас обработана только выборка.
3. **Telegram и YouTube, ещё 8–14 часов.** Подтвердить принадлежность каналов компаниям. Для публичных каналов — публичные страницы; если они не дают посты, использовать существующий Telethon-клиент, не вступая массово в каналы. До пяти последних доступных сообщений на канал, дата, URL, текст, связь с компанией. YouTube — yt-dlp/поиск XMLRiver, проверка года, канала и содержания; отдельно приглашения, репортажи, обзоры. Не скачивать видео для обычной ленты: достаточно метаданных и ссылок.
4. **Программа и спикеры, ещё 6–12 часов.** Найти подтверждённую программу 2026, обработать HTML/PDF, связать людей с организациями, искать публичные профили через XMLRiver и сверять по роли. Пока актуальная программа не подтверждена.
5. **Новинки и итоговый обзор, ещё 12–16 часов после выставки.** Реестр «участник → продукт → подтверждающая ссылка → статус». Анонс в карточке не означает фактический показ. Итоговый текст пишет Codex по источникам. Если у участника нет подтверждений, сохранять «данные не найдены», а не придумывать новинку.

Диапазоны этапов могут частично перекрываться. Глобальная оценка полной версии 40–70 часов предполагает доступные источники; нижняя граница не гарантирует ручной разбор каждой карточки. Массовый обход — отдельный длительный запуск, его календарное время зависит от ответов сайтов.

## Модель данных для полной версии

Основа MVP — `exhibitors.json`: id, name, country, stands, about, website, contacts, source_url, статусы сбора. Для расширения:

- `contact_sources`: тип контакта, значение, компания, URL источника, время проверки.
- `channels`: URL, тип (канал/бот/профиль), подтверждённая компания, URL подтверждения.
- `feed`: channel_id, message_id, date, text, url; не более пяти последних сообщений на канал в витрине, без потери истории в хранилище.
- `program.events`: дата, время, площадка, тема, speaker_ids, source_url, год источника.
- `people`: имя, организация, роль, ссылки и доказательство сопоставления.
- `videos`: URL, заголовок, канал, дата, тип материала, год выставки и статус проверки.
- `items`: компания, название продукта, анонс/подтверждено, ссылки и дата подтверждения.

Все эти разделы подключены к витрине; пустой JSON отображается как явный статус. Заготовленные рендереры не заменяют сборщики. Для полноценной ленты потребуется добавить сортировку по датам, группировку по каналам и отображение видео-превью.

## Риски и меры

| Риск | Решение |
|---|---|
| Старые даты и архивные страницы в актуальном меню | Сверять основной текст, год, место и дату публикации; не импортировать сомнительную программу |
| Каталог меняется или параметр limit перестаёт работать | Проверять остаточную пагинацию, сохранять снимок и ошибки; при изменении добавить обход страниц |
| JS-сайты, SSL, таймауты, антибот | Ограниченные повторы, отчёт по ошибкам; браузерный fallback только при необходимости. Не отключать проверку TLS |
| Telegram-ссылка ведёт в бот или личный профиль | Подтвердить тип и владельца до загрузки в ленту; не совершать массовые вступления |
| Видео MITEX 2025 ошибочно принято за 2026 | Проверять заголовок, содержание, дату и год события; приглашения отделять от прошедших мероприятий |
| Новинки упомянуты без названий, моделей или подтверждения показа | Сохранять анонс отдельно; итоговый обзор писать после события, показывать пробелы покрытия |
| Однофамильцы спикеров | Сверять организацию и должность, не выводить неподтверждённый профиль как официальный |
| Стоимость массового поиска | Поиск Google/Яндекс только через XMLRiver; кэш, счётчик запросов, бюджет перед запуском. MVP без платных API |

## Принятые допущения

Локальный сайт, разовый снимок, публичные корпоративные контакты, бесплатный сбор из источников. Уточнения не блокируют прототип. Перед переходом к регулярной публичной версии потребуется определить частоту обновления, аудиторию публикации и бюджет платного поиска. Публиковать локальную папку или создавать внешние аккаунты в рамках MVP не требуется.

## Критерии готовности полной версии

Каждый участник учтён в снимке; у каждого сайта есть успешный результат или объяснение ошибки. Telegram-адреса проверены, для каждого доступного канала сохранено до пяти последних постов. Программа относится к 2026, профили спикеров подтверждены. У всех видео и новинок есть источник и статус. Итоговый обзор содержит явный охват, а не утверждение «новинки всех участников» при неполных данных.
