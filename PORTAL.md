# MITEX: портал в оформлении столярного фестиваля

Вход: https://catalog.mitexpo.ru/expositions/exposition/7054.
Это независимый навигатор, не официальный сайт MITEX.

## Данные и интерфейс

- `data/portal/participants.json`: подробные карточки, все рубрики и контакты,
  сведения о вложениях, источники и даты проверки.
- `data/portal/program.json`, `people.json`: актуальная программа и спикеры.
- `data/portal/telegram_posts.json`: полные сообщения для локального анализа.
- `data/portal/post_analysis.jsonl`: результат работы встроенной модели Luna.
- `data/portal/giveaways.json`: только подходящие розыгрыши на стендах.
- `portal_web/`: оформление и шаблоны нового портала.
- `docs/`: опубликованная статическая версия, страницы участников и спикеров.
- `docs/media/source-cards/`: снимки исходных карточек каталога.
- `artifacts/`: результаты проверок и снимки нового интерфейса.

Прежние `web/`, `site/`, `scripts/build.py` и октябрьские `data/site/` сохранены.
Новый сбор не выдаёт их за актуальный срез. Чужой тестовый каталог
`skill-test-20261110/` не изменяется.

## Повторение сбора

```powershell
python -X utf8 scripts/refresh_portal_catalog.py
python -X utf8 scripts/refresh_portal_program.py
python -X utf8 scripts/collect_portal_telegram.py
python -X utf8 scripts/prepare_portal_media.py
```

После получения новых постов нужен содержательный анализ самим агентом.
Скрипт сбора не выполняет этот анализ и не вызывает внешнюю LLM.
Порции `analysis_input_*.json` фиксируются для одного прогона; при новом срезе
агент должен подготовить новый набор порций/ID, а не использовать старые результаты
для изменившихся сообщений. Сохранять результаты по ID и хешу текста.

```powershell
python -X utf8 scripts/merge_portal_analysis.py
python -X utf8 scripts/capture_portal_sources.py
python -X utf8 scripts/build_portal.py --production
python -X utf8 scripts/check_portal.py
```

Публикация предполагает отдельную проверку снимков, ссылок и отчёта об охвате.
Автоматического ежедневного обновления и автоматического запуска агентной модели
в этом проекте нет. Ключи находятся только в игнорируемом `.env`.

## Ограничения

Десять последних сообщений — ограниченный срез, а не вся история канала.
Ноль подтверждённых розыгрышей в срезе не доказывает их отсутствие на выставке.
Неизвестное время не превращается в полночь, дедлайн заявки — во время розыгрыша.
Онлайн-конкурсы, скидки и подарки за визит отделены от розыгрышей на стендах.

В интерфейсе используются короткие выдержки из Telegram с оригинальными ссылками
и ограниченные превью. Полные тексты нужны локально для анализа.
Видеоматериалы могут храниться ссылками; это не скачанные видеофайлы.
Большие каталоги открываются у участника; локально сохранённые большие файлы
находятся в `data/attachments/` и не публикуются в GitHub Pages.
Ошибки источников и неподтверждённые поля сохранены в реестрах охвата.
