## Аудит глазами шести посетителей

Это экспертная проверка по ролям, а не интервью с посетителями.

1. Нетерпеливый: ссылка «Найти на схеме» сразу под названием компании; название, зал и стенд на странице видны до схемы. На узком экране верхние отступы занимали лишнее место — сокращены.
2. Скептик: есть официальная карточка, полная схема организатора, дата проверки и пояснение о сохранённой копии. Сопоставление по ID, без угадывания по имени.
3. Пользователь телефона: горизонтальной прокрутки нет, кнопки не меньше 44 пикселей, масштаб управляется отдельными кнопками. Схема перетаскивается отдельно от страницы. Номер на исходном плане мелкий — доступны приближение и отдельная текстовая строка стенда.
4. Тестировщик: проверены четыре зала, неизвестный ID, компания без геометрии, изменение масштаба, «Весь зал» и возврат «К стенду». Неизвестный участник не открывает чужой стенд.
5. Посетитель выставки: выбранный стенд первоначально был оранжевым, как часть исходных стендов. Исправлено: бирюзовая заливка с тёмной толстой рамкой, пояснение цвета над планом. Есть контекст соседних стендов и общий вид зала.
6. Закупщик: доступны точная ссылка на компанию, источник и возвращение в каталог. Автоматическое построение маршрута не входит в этот сценарий.

Общая проблема ролей посетителя и скептика — неоднозначность первоначального оранжевого выделения — исправлена. Других препятствий основному действию на проверенных состояниях не обнаружено.

- Исходные SVG просмотрены: нет скриптов, обработчиков событий, foreignObject и внешних href. В приложении они загружаются как изображения; интерактивные контуры созданы безопасным DOM API.
- Сборка, scripts/check.py и синтаксис обоих JS прошли проверку. Старые разделы и данные участников не обновлялись.

Ограничение источника: официальный интерфейс не меняет URL при выборе компании; обработчик открытия участника по параметру/фрагменту не найден.
