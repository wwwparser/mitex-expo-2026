# Проверка портала MITEX

10 ноября 2026, рабочая сборка из docs.

Пройдено: 826 HTML-страниц проверены на локальные ссылки, битых — 0;
745 снимков исходных карточек присутствуют. 642 сообщения получили отдельную
запись анализа; дубли ID отсутствуют. Необработанных карточек, материалов,
новостных вкладок и найденных вложений нет.

Chromium, 1440×1000 и 390×844: главная, каталог, программа, спикеры,
лента, розыгрыши, видео и полная карточка ADA. 16 состояний страниц;
горизонтальное переполнение — 0, ошибки JavaScript — 0, неудачно загруженные
изображения на проверенных экранах — 0.

Взаимодействия: выдача 24 → 48, поиск ADA, сброс, фильтр зала,
совместный фильтр рубрики и зала, переход в последний пункт меню с телефона,
якорь дня программы, фильтр онлайн-объявлений, ссылка на снимок оригинала.
Проверены Tab-переход к ссылке пропуска и переключение темы.

Результаты: static-check.json, browser-check.json, interaction-check.json,
six-visitor-audit.md и снимки first/full в этой папке.

Внесённые исправления: отдельный фильтр товарных рубрик вместо смешения с залами,
явные расхождения времени в двух анонсах, ссылки на план и билет, индикатор
горизонтальной прокрутки меню телефона. Визуальная основа эталона сохранена.

Ограничения: 33 вложения источников недоступны; у одной вкладки новостей HTTP 500.
Крупные файлы открываются у участников, локальные копии находятся вне публикации.
Проверка не подтверждает ответы на письма, действительность призов, фактическое
проведение выступлений и воспроизведение каждого внешнего видео.
